# 快速开始

交融超级智能体是一款为深度工作而生的桌面端 AI 助手，以“快速、专注、隐私优先”为核心设计理念，将 AI 能力融入日常工作流。

## 产品简介

- **极致效率，即刻响应**：基于原生应用架构深度优化，指令交互零延迟。内置“深度工作专注模式”，智能屏蔽冗余干扰，帮助您聚焦核心任务。
- **专业赋能，触手可及**：拥有流畅的通用对话能力，贴合实际业务场景。支持一键生成 PPT、多文档智能分析、实时联网搜索等功能，让复杂操作化繁为简。
- **安全可控，开放共赢**：坚持隐私优先设计，支持本地数据处理与端侧加密，确保企业核心信息不外泄。同时，通过 MCP 协议无缝集成主流 AI 模型，并持续扩展技能生态。

交融超级智能体不仅是工具，更是您深度思考与高效决策的可靠伙伴。

## 产品使用

### 交融对话

进入首页后，点击“交融对话”进入对话页：

![交融对话入口](/product-manual/chat-entry.png)

在对话页，可以通过“选择项目”选择文件夹，通过 `@` 引用文件，通过 `/` 调起命令，通过 `+` 添加一个或多个附件：

![交融对话输入能力](/product-manual/chat-input.png)

### 管理与新增 Agent

在首页点击“管理 交融超级智能体 Agent”：

![Agent 管理入口](/product-manual/agent-entry.png)

在管理页面，可以编辑及新增 Agent。编辑项包括名称、启用状态、描述、头像、系统提示词、内置工具的启用等：

![Agent 管理页面](/product-manual/agent-manage.png)

### 其他设置

在对话页面，点击左下角的“设置”进入设置页面：

![设置入口](/product-manual/settings-entry.png)

#### 通用设置

可以设置文件最大大小、代理模式、开机时启动交融超级智能体等：

![通用设置](/product-manual/settings-general.png)

#### 显示设置

可以设置语言、主题、系统通知、文字大小、字体、投屏保护、悬浮按钮等：

![显示设置](/product-manual/settings-display.png)

#### 目录环境

可以查看对话使用过的项目目录，也支持直接打开及设为默认：

![目录环境](/product-manual/settings-directory.png)

#### 记忆

支持查看、配置并管理每个 Agent 跨会话记住的内容。记忆按 Agent 隔离：

![记忆设置](/product-manual/settings-memory.png)

#### 快捷键

可以对“显示/隐藏窗口”、“新会话”、“聚焦搜索”、“切换侧边栏”等操作进行快捷键设置：

![快捷键设置](/product-manual/settings-shortcuts.png)

#### 关于

可以查看当前版本，并执行“检查更新”。如有新版本发布，可在此安装下载：

![关于与更新](/product-manual/settings-about.png)

### 技能中心

#### 技能市场

技能市场内置经营投标、工程建设、合约法务、综合办公、软件研发五大核心领域的实用技能，覆盖全业务链：

![技能市场](/product-manual/skills-market.png)

点击某一技能进入技能详情页：

![技能详情](/product-manual/skills-detail.png)

点击“试一试”跳转至对话页，并附带相应话术：

![技能试一试](/product-manual/skills-try.png)

#### 新建技能

支持两种方式新建技能，让专属技能随需而变：

- **通过对话直接生成**：使用内置的“技能创建”技能，输入相关要求即可。
- **上传文件快速定制**：支持上传文件夹或 `.zip`，内容可包含一个或多个非嵌套技能目录；也可以上传单独的 `.md` 文件。系统并不能确保技能的可用性，请自行验证。

### 知识库

交融超级智能体已接入交融问之的知识库。点击左侧栏“知识库”进入页面，进行查看、编辑、提问等操作：

![知识库](/product-manual/knowledge-base.png)

也支持在对话中选择知识库的某个库、文件夹或文件进行引用，基于选择的内容进行总结、提问以及写作：

![对话引用知识库](/product-manual/knowledge-reference.png)
